# Roan's Candle & Diffuser Landing Page

Single-page website template for small-batch soy candles and hanging car diffusers featuring modular CSS, full theme/dark mode support, responsive layouts, and modern typography via Google Fonts.

## Project Structure
* `index.html` — Main document structure, semantic sections, SVG placeholders, and content.
* `styles.css` — Custom properties, CSS grid/flex layouts, CSS-based illustration artwork, and keyframes.

## GitHub Pages Setup Instructions

1. **Create Repository**: Go to GitHub, create a new repository (e.g., `roans-candles`).
2. **Push Code**: Add `index.html` and `styles.css` to your main branch.
3. **Enable Hosting**:
   * Navigate to **Settings** > **Pages** in your repository.
   * Under **Build and deployment**, set Source to **Deploy from a branch**.
   * Select **`main`** branch and root **`/`** folder, then click **Save**.
4. Access your live site at `https://<username>.github.io/<repository-name>/`.
